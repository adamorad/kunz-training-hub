# Security

This runs a real hackerspace's training data, and the code is public on purpose. Poking at it is welcome; breaking it for other members is not.

If you find a hole:
1. Don't use it on the live site beyond what you need to confirm it.
2. Tell a key-holder at the space, or open a GitHub issue without exploit details and ask for a contact.
3. Better: send a pull request with the fix. Bonus points for a test.

In scope: anything that lets someone join without the space code, act as a trainer without a key-holder's verification, edit or delete someone else's data, read Telegram handles without being a member, or take the site down cheaply.
